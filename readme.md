Math3D

Build the renderer into /dist

npm run build

Functionality

- 3D surface viewer with implicit, graph (z=f(x,y)), and parametric modes.
- Surface presets including classical, minimal, and custom expressions.
- Lighting, materials, wireframe, slicing, and contour controls.
- Probe tools for normals/tangents and curvature (graph/implicit overlays).
- Domain pickers and saved domain presets for graph and param surfaces.
- Compare mode with side-by-side views and shared camera.
