# Install and Run

## Requirements

- Node.js 24 or newer
- npm 10 or newer

## Install

```bash
git clone https://github.com/expert10000/Math3D.git
cd Math3D
npm install
```

## Desktop app

```bash
npm run build:core
npm run build
```

## Browser app

```bash
npm run dev:web
```

Static build + preview:

```bash
npm run build:web
npm run preview:web
```

Static files are written to `apps/web/dist/`.
