# Samsung project collection

`samsung-projects.json` contains the 25 independent saved projects exported from
the Samsung library on October 4, 2026 and adapted through the desktop project
transfer boundary. The collection ships in a lazy, offline renderer asset.

In **Projects**, choose **Import Samsung projects (25)** to add missing projects
to the local saved-project library. The import keeps any existing version with
the same project identity, including user edits, favorites and activity. It does
not activate a project or change the current workspace. Repeating the import is
safe; after a storage failure, retrying adds only the remaining projects.

Titles that occur more than once represent distinct saved project identities.
The collection retains the original source definitions, history, metadata and
available verified Mesh, Volume and Graph point-table resources. It includes
Enneper, Catenoid, Helicoid, implicit and parametric examples, Graph studies and
mixed acceptance projects. The PRJ21 mixed project intentionally remains a
compatibility preview because not all of its saved Volume representations and
resources are supported. The other 24 projects qualify for desktop opening.

Collection validation uses the normal project/replay/resource parsers before
any library writes. Each imported project and its resources commit together;
already imported projects remain available if a later project cannot be stored.
The collection is distributed with Math3D under the repository license.
