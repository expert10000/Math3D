# GRA-11.3: planar phase portraits

Graphs saves a planar autonomous system `x′ = f(x,y)`, `y′ = g(x,y)` as one editable phase-portrait object. It stores finite rectangular x/y bounds, a positive time horizon of at most 100 in **each** direction, and 1–8 initial points. Equations use the shared checked Graph expression language and document parameters. Create and edit are single undoable scene commands. The required document capability is `graph2d.phase-portrait.v1`.

The shared sampler draws a bounded grid of normalized direction arrows and integrates an orbit forward and backward in **time** from each initial point. It uses RK4 step doubling with Richardson correction, local tolerance `10⁻⁶(1+max(|position|,|next|))`, at most 2,048 accepted steps per direction, at most 12,000 expression evaluations or the scene's lower budget, and the host deadline. Each orbit reports accepted/rejected steps and separate stop reasons: time horizon, domain boundary, equilibrium, singularity, sample limit, step limit or deadline. A phase portrait requires linear axes; logarithmic axes report an unsupported-scale diagnostic. Orbit samples are approximate and are not exact probes or analytic solutions.

Desktop/web: **Graphs → Add phase portrait** in Functions. Edit both derivatives, x/y bounds, time horizon and initial points, then **Save phase portrait**. Select it to inspect the equations, seed list, direction-arrow count and per-orbit stop reasons. The Functions card supports edit, hide, delete and undo. Mobile exposes **Add phase portrait** with the same object contract; enter up to eight `x,y` initial points, one per line. The live plot and exported plot distinguish direction arrows from solution orbits and mark the saved initial points.

The exact-reference corpus includes the rotation system `x′=y, y′=-x`: a seed `(1,0)` remains on the unit circle and returns to its start after `2π` in either time direction. A saddle `x′=x, y′=-y` checks domain exits and the invariant `xy=1`; `(0,0)` checks equilibrium. Budget, invalid seed, capability, persistence, undo and mobile projection checks cover the document boundary. Physical mobile visual and accessibility checks remain in the release gate.

[GRA-11.5](graph2d-gra11-equilibrium-classification.md) adds local classification. [GRA-11.6](graph2d-gra11-interactive-seeds.md) adds canvas placement and dragging of initial points.
