# GRA-16: aligned multi-channel Fourier comparison

The desktop Graphs Inspector can compare the selected point series with up to three additional point series in the same document. Every channel must have its original, checksum-checked point-table sidecar. Each complete in-domain series is tested for finite, strictly increasing, uniform x spacing; every pair must then have exactly the same ordered x coordinates. The analysis declines missing rows, gaps, changed sidecars, mismatched grids and jobs above the selected row budget. It does not infer an alignment or resample data.

Scientific imports must all declare the same x and y units, and the selected x unit must agree with their provenance. A scientific import cannot be compared with a manually imported series that has no declared units. For entirely manual series, the x unit entered in the panel and the generic y unit are user assumptions, called out in the result warnings. This checks metadata consistency; it does not establish a physical calibration or re-open an external scientific bundle. Each returned spectrum retains its own object ID, label, point-table checksum, optional scientific origin and amplitude/phase bins. The combined result records all channel checksums and an exact-grid alignment rule. CSV exports one common frequency column and amplitude/phase columns per channel, with per-channel source metadata.

The panel renders a separate amplitude plot for each channel, labels its independent vertical peak scale, and lets the user inspect one channel's numerical bins at a time. Single-channel CSV/JSON formats remain unchanged. The existing single-series analysis, worker cancellation, row budgets and mobile single-channel behavior remain available. Known-tone, missing/gap, shifted/short grid, changed-sidecar and unit mismatch tests cover the core, and an Electron test covers the two-channel desktop workflow. Automatic resampling and mobile multi-channel interaction are separate future slices.
