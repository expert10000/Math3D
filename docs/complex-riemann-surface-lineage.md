# Complex Riemann-surface lineage

Complex Analysis 3D value surfaces are no longer anonymous preview meshes. Each
build publishes three revision-qualified F07 artifacts: the sheet mesh, its scalar
field, and a seam table. The compact handoff records the source function and AST,
branch/cut policy, result references, grid/domain generation parameters, and sheet
gluing transitions.

The same handoff contains explicit derived relationships for **Surfaces** and
**Mesh**. In **Complex Analysis → Branch Lab**, build a 3D value surface and return
to Branch Lab to inspect **Revisioned Riemann-surface handoff**. **Locate vertex 0
in Complex source** demonstrates the reverse mapping from a derived sheet vertex to
its sheet, parameter point, source revision, function, AST, branch policy, results,
and generation record.

If the Complex document advances, the previous handoff remains inspectable but is
shown as a preserved stale revision. It is never silently rebound to newer source
state.
