# GRA-11.2: linked initial-value trajectories

Graphs now saves a trajectory as a separate object linked by ID to an authored slope field `dy/dx = f(x,y)`. The trajectory stores only its initial point `(x₀,y₀)`, label and display style. Editing the field changes the computed solution; deleting a field with linked trajectories is refused. Each create or edit is a normal undoable Graph scene command. The document advertises `graph2d.trajectory.v1` and validates that the linked field exists and the finite seed lies in its authored bounds.

The shared core integrates in both directions along x with RK4 step doubling and Richardson correction. It uses local error tolerance `10⁻⁶(1+max(|y|,|y_next|))`, caps accepted steps at 2,048, expression evaluations at 12,000 or the scene budget, and step length at one sixty-fourth of the authored x span. It stops at the field x/y bounds, a detected singularity, an evaluation/step budget, or the host deadline. The sampled result exposes the stop reason and accepted/rejected steps in the Inspector; it does not claim an exact analytical solution. A failed step cannot connect points across the detected gap. Trajectories, like slope fields, require linear axes and do not create an exact point probe. Narrow discontinuities that fall between numerical evaluations may still require a smaller field domain or later discontinuity analysis.

Desktop/web: **Graphs → Add slope field → Save slope field → Add trajectory** on that field's Functions card. Enter the initial x and y, then **Save trajectory**. The initial point is marked on the line. Select the solution to see its linked source and integration status in the Inspector. Edit or hide it from its Functions card. Mobile uses **Add trajectory for [field]** on the slope field's Functions card, with the same shared document, sampler and undo flow.

Exact-reference tests cover `y'=0`, `y'=x`, and `y'=y`, backward and forward integration, linked field edits, invalid seeds and deletion, persistence, a pole at `x=1`, work limits and mobile projection. Browser UI checks cover create, rendering, Inspector status and seed edit. Physical-device visual and accessibility evidence is still part of the existing mobile release gate. [GRA-11.3](graph2d-gra11-phase-portraits.md) adds planar autonomous phase portraits; general vector fields remain later work.
