# SSR-00 — existing-to-generic compatibility map

**Status:** Complete as an inventory and migration boundary (2026-10-12). This map defines no new file format, importer, worker or UI. It compares the current `expert10000/theory-lab` producer with Math3D's reader after M3D-Q07 delivery; M3D-Q08–Q10 remain open.

## Proof fixtures and invariants for the next tranche

**Quantum proof:** use the already pinned `tests/fixtures/quantum-scene-orbitals/orbital-2p.qscene`. It exercises binary real/imaginary amplitudes, complex field semantics, Cartesian `a0` coordinates and derived density/phase views. It must still open through the original quantum reader with unchanged fingerprints. The new generic adapter may wrap verified descriptors; it must not rewrite source arrays or claim that derived density was supplied.

**Non-quantum proof:** add a deterministic, bounded 2D scalar field `f(x,y)=sin(x)cos(y)` with dimensionless values on explicitly declared Cartesian x/y axes. This will be a new generic fixture, not a Theory Lab export or a Python job. Admit its binary array, show an appropriate view, pick an exact sample and refuse modified bytes, invalid dimensions, missing units or mismatched metadata.

**Shared acceptance:** both fixtures use the same generic validator, artifact reader, selection reference and existing viewer/picking infrastructure. Original quantum-scene/v1|v2 tests remain green. Reopening after restart re-verifies the exact source; no comparison relies on a rendered pixel or a filename alone. Unsupported semantic types and unknown versions fail closed. Generic Project linkage is conditional, not part of the first proof.

**Explicit non-goals of SSR-00–03:** no new physics, Python provider, Jupyter kernel, direct Lab worker call, editable Project promotion, arbitrary expressions, large streaming volume or replacement of the existing quantum viewer.
