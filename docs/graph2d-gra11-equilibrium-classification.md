# GRA-11.5: local equilibrium classification

Each residual-checked equilibrium candidate from [GRA-11.4](graph2d-gra11-nullclines-equilibria.md) now receives a bounded local Jacobian estimate. Two central-difference step sizes and one-sided agreement checks use the phase portrait's existing expression-evaluation and deadline budget. The artifact records the 2×2 Jacobian, trace, determinant, two estimated eigenvalues, the finer step, a derivative-consistency measure, and a reason when classification is inconclusive or unavailable. The source document schema does not change; edits recompute the observation.

The Inspector and mobile analysis sheet distinguish saddles, stable/unstable nodes and stable/unstable spirals. A purely imaginary pair is labelled **linear center** with nonlinear stability undetermined. A zero or near-zero eigenvalue is labelled **nonhyperbolic** and inconclusive. If derivatives disagree across sides or scales, the class is **unresolved**; a boundary, singularity or exhausted budget makes the estimate unavailable. The near-repeated-eigenvalue transition is also left unresolved rather than deciding node versus spiral from small numerical differences.

These are local conclusions from a numerical Jacobian at an approximate equilibrium. The stability of a hyperbolic classification follows the local linearization when the underlying field is differentiable and the candidate is a true equilibrium; this numerical display does not certify either premise. Contour search can still miss an equilibrium. The circular-flow, saddle-flow and three-equilibrium Gallery presets provide reference cases; exact-reference tests additionally cover stable/unstable spirals, a nonhyperbolic equilibrium and a nonsmooth corner. Browser checks cover the Inspector labels. Physical mobile visual and spoken-accessibility signoff remains in the release gate.
