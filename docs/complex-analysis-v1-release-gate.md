# Complex Analysis v1 release gate

Complex Analysis v1 is accepted at C12. The canonical release command is:

```powershell
npm run test:complex:v1:acceptance
```

It runs the complete Complex parser/AST, platform corpus, command, artifact,
numerical, exact/Sage, cancellation, persistence/replay, branch continuation, and
Riemann-surface lineage unit suite; then TypeScript and the production renderer
build; then the focused Electron journeys for lab reachability, preview artifacts,
numerical/exact results, continuation, lineage, and the integrated v1 workflow.

The integrated contract is **define → explore → analyze → save → reopen → replay →
derived handoff**. Every scientific result and large artifact is qualified by the
same document ID, source revision, structural hash, and generation. Approximate
results remain numerical; exact results name their engine; unsupported or stale
work remains explicit. Screenshots are retained as rendering evidence only and are
never used as a mathematical oracle.

Legacy lab layouts and illustrative presets remain reachable through documented
adapters. No compatibility route was removed at C12 because none was independently
proven redundant by a parity gate. Future removal must name its replacement and add
an equivalence test first.

## Acceptance matrix

| Gate | Evidence |
| --- | --- |
| Function/AST | deterministic parse, grammar restrictions, preview compilation, scientific corpus |
| Mutation | one command adapter, transient typing, undo/redo and imported-command parity |
| Analyze | numerical tolerances, exact MVP, constrained Sage requests, cancellation and limits |
| Persistence | canonical save/reopen, replay hashes, unavailable artifact semantics, structured export |
| Branches | adaptive continuation, closure/discriminant checks, qualified monodromy |
| 3D handoff | revisioned mesh/scalar/seam artifacts, Surfaces/Mesh relations, vertex locate-back |
| UI | all six labs reachable; preview, result, continuation, and lineage Electron journeys |
