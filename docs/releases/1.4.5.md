# Math3D 1.4.5 Release Checklist

## Release Scope

Math3D 1.4.5 is a stabilization release for the currently implemented
extension subset. Do not promote unfinished experimental features to stable or
add large new features during release preparation.

## Version

- [x] Root Electron package version is `1.4.5`.
- [x] Workspace app and shared-package manifests use `1.4.5`.
- [x] Renderer manifest uses `1.4.5`.
- [x] Mobile Expo app version uses `1.4.5`.
- [x] Desktop About/system-info UI reads `app.getVersion()` and displays `1.4.5`.

## Installer Contents

- [x] Desktop renderer bundle is packaged at `renderer/dist`.
- [x] Standalone web bundle is built during installer packaging.
- [x] Standalone web bundle is installed under `resources/web-app`.
- [x] Installer verification checks `resources/web-app/index.html`.
- [x] Bundled Python worker remains installed under `resources/python-worker`.

## Release Smoke Scenes

### Basic primitives

1. Open Geometry, then Procedural.
2. Load `Release smoke: basic primitives`.
3. Confirm the box, sphere, and cylinder render and remain selectable.
4. Confirm Scene and Object panel selection stays synchronized.

### Dependency tree

1. Load `Release smoke: dependency tree`.
2. Open Construct and inspect the dependency tree.
3. Change a source object and confirm downstream ordering remains valid.

### Construction history

1. Load `Release smoke: construction history`.
2. Open History and step through the timeline.
3. Navigate backward and forward without UI desynchronization.

### Selected extension subset

1. Load `Release smoke: extension subset`.
2. Exercise supported Geometry-to-Mesh and analysis actions.
3. Confirm unfinished actions remain disabled, planned, or experimental.

### Object deletion and recompute

1. Load `Release smoke: deletion and recompute`.
2. Delete the source object.
3. Confirm dependents become safely invalid instead of crashing.
4. Restore the source and confirm selection refreshes after recomputation.
