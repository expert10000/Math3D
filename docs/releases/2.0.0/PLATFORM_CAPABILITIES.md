## Evidence and boundaries

- Host facility facts come from `renderer/src/kernel/rendererPlatformCapabilities.ts` and `apps/mobile/src/services/mobilePlatformCapabilities.ts`. They report DOM, WebGL2, workers, storage, desktop bridges, network and touch separately. They do not infer scientific operation support from a runtime name.
- Desktop Project import/export and browser Project journeys use `renderer/src/projects/projectTransfer.ts`, the Project package validator, and the unified Projects acceptance tests. Required source sidecars must verify before full open; optional analysis caches can remain unavailable.
- Mobile named Project previews use `apps/mobile/src/models/mobileProjectPreview.ts` and `mobileProjectExplorer.ts`; document editing support varies by module and source shape. A preview is not a native editor. Mobile package resource checks are in `mobileProjectResources.ts`.
- Sage availability comes from the operation capability manifest and live backend probes shown in `renderer/src/features/computeCenter/SageRuntimeInspector.tsx`. A successful network probe or an installed binary alone is not a supported Sage operation.
- Windows source-build desktop and local browser can be exercised in CI. The [self-signed Windows RC1](https://github.com/expert10000/Math3D/releases/tag/v2.0.0-rc.1-selfsigned) passed clean installed Fresh and Upgrade on the exact frozen source and installer, including four connected journeys with a live SageMath 10.10 route; its receipts explicitly say `gaApproved:false`. Hosted browser still depends on a qualified deployed gateway, credentials, and storage.
- The [Linux installed-package baseline](LINUX_PACKAGE_BASELINE.md) now records exact frozen-source `300d2420` AppImage/deb/rpm bytes, first launch, bundled-worker Graph and Mesh Project cold reopen, published 1.7 upgrade, and restored-profile rollback on Ubuntu/Fedora. [Package build](https://github.com/expert10000/Math3D/actions/runs/45192925634), [installed](https://github.com/expert10000/Math3D/actions/runs/45399341218), and [upgrade/rollback](https://github.com/expert10000/Math3D/actions/runs/45399361201) runs passed. The packages are not public RC1 assets; Linux publication and platform-claim review remain open.
- The [Android signed internal APK baseline](ANDROID_DEVICE_BASELINE.md) now records a clean `300d2420` / build `200001` internal APK, matching established certificate, and Android 16 emulator navigation, layout, lifecycle, Project package, and recovery evidence from [run 45399396461](https://github.com/expert10000/Math3D/actions/runs/45399396461). No physical device was connected; a matching phone receipt and public AAB remain open.
- The Project import review disables save and open when the persistent-storage probe fails and shows the host reason. It also keeps full open disabled for a Project with missing required source bytes or an unsupported editor while allowing an inspectable preview.
- [Source-host acceptance](PLATFORM_SOURCE_ACCEPTANCE.md) records the tested Windows Electron and local Chromium build hashes, commands, locale coverage and observed journeys. Browser offline coverage starts after page load; it does not establish a cold offline launch. A local browser network probe observes `navigator.onLine`, while actual remote compute needs an independent backend check.
- [Hosted web qualification](HOSTED_WEB_ACCEPTANCE_2026-11-25.md) ties the production alias to the immutable Cloudflare build and records the passing Project/Workbook/Note, scientific ZIP, persistence, permission, narrow-layout, and offline-after-load subsets. Sampled `/api/worker/*` and `/api/sage-private/*` requests returned static fallback HTML or HTTP 405, so hosted scientific runtime claims remain blocked.
- `tests/unit/m3d20PlatformMobile.test.ts` verifies a portable research package and sidecars through mobile preview/export/reimport, names missing Graph source bytes, refuses import when sandbox storage is unavailable, and rejects unknown Project fields. This is a model test with mocked Expo document storage, not an Android device run. The mobile host may save a verified preview but does not claim to restore every desktop editor.
