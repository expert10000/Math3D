# Math3D 2.0 release closure

**Updated:** 2026-11-24. The [2.0.0 RC1 self-signed Windows prerelease](https://github.com/expert10000/Math3D/releases/tag/v2.0.0-rc.1-selfsigned) is published and its public downloads passed a fresh byte audit. This closes the scoped prerelease, **not** the trusted Windows GA or the other platform gates. The stable `v2.0.0` tag has not been created.

The former 2–3 day estimate was a prerelease planning target, not a current GA estimate. The [2.5-or-later memory track](../2.5.0/MEMORY_QUALIFICATION.md) retains the 800-switch mixed-route plateau, viewer disposal, and two-hour soak. Those measurements have **not** passed for 2.0. The [release scope](RELEASE_SCOPE.md) and [platform matrix](PLATFORM_CAPABILITIES.md) limit every host claim to its cited evidence.
