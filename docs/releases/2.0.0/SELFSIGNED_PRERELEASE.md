# Windows 2.0 self-signed prerelease path

**Status:** preparation only. This path is separate from the trusted, signed GA candidate in `SIGNING_READINESS.md`. It produces a stable-identity 2.0 installer signed with a certificate created by the Math3D owner. That certificate is **not publicly trusted**. Windows may show an unknown-publisher or SmartScreen warning; a cryptographically intact signature does not remove those warnings. Do not describe this artifact as a trusted Windows release.

The owner created one exportable Code Signing certificate on 2026-11-19 with thumbprint `38F403CE0B42720EE5AFD61422D6A2C22EB733D9`. Its PFX, public certificate and DPAPI-protected export password are stored outside the repository under the owner's Windows profile. The private key and password must never be committed, uploaded as release assets or pasted into chat. The public certificate and thumbprint may be distributed so a tester can inspect the signer. Preserve a separate owner-controlled backup before relying on this identity for later builds; the DPAPI password file is tied to the creating Windows account.

## Build on one reviewed commit

1. Merge reviewed prerelease source and choose one clean commit. Run `node scripts/prepare-release20-freeze.mjs <new-path-outside-checkout>` and independently review the resulting manifest and SHA-256. Any source change requires a new freeze.
2. On the owner's Windows host, install the exact root and renderer npm locks and the frozen Python worker dependencies used by `release20-candidate.yml`. Keep the PFX and protected password outside the checkout.
3. Run `scripts/build-release20-selfsigned-prerelease.ps1` with the reviewed `-FreezeManifest`, owner-only `-PfxPath`, `-PasswordDpapiPath`, public `-PublicCertificatePath`, and `-ExpectedThumbprint`. `-PreflightOnly` checks the clean source, freeze and certificate without building. The script pins NSIS, builds the stable 2.0 app, signs the packaged app, installer and frozen worker, checks the worker protocol, validates each signature and timestamp, and generates a prerelease manifest, SBOM and corresponding-source bundle under a new temporary output directory.
4. Independently compare the output hashes with the manifest and test the **same installer bytes** on a clean Windows profile, including first launch, bundled worker, Project reopen, and the published 1.7 upgrade and rollback. Record any unavailable live Sage journey separately. Stage a GitHub **draft prerelease** only after those exact-byte checks; publication is a later decision.

For clean hosted-runner transfer, the [installed acceptance route](SELF_SIGNED_WINDOWS_INSTALLED_ACCEPTANCE.md) permits a separate, unpublished **test-handoff draft** after the final installer is signed but before step 4's installed checks. It contains only the installer and public manifests, uses a temporary staging tag instead of `v2.0.0`, and remains explicitly unqualified. The normal draft prerelease in step 4 still waits for exact-byte installed receipts. Neither draft publishes the release or carries the private PFX or password.

The verifier `scripts/verify-release20-selfsigned-prerelease.ps1` requires the expected self-signed Code Signing certificate, current validity, an RFC 3161 timestamp, and intact Authenticode file hashes. It accepts the expected `UnknownError` trust status for a self-signed root, while rejecting `HashMismatch` and other integrity failures. Its report explicitly sets `publiclyTrustedPublisher: false`. The existing trusted candidate preflight and `verify-release20-signatures.ps1` still require a publicly valid signer and are not weakened by this path.

The local signing probe used a copy of the exact unsigned Dev installer from [run 44498966768](https://github.com/expert10000/Math3D/actions/runs/44498966768). `signtool` signed and timestamped that copy with the owner certificate. Windows reported the expected untrusted-root error; the prerelease verifier accepted the intact copy and refused a deliberately modified copy with `HashMismatch`. This probe is **not** an installed prerelease acceptance or the final stable-identity artifact.
