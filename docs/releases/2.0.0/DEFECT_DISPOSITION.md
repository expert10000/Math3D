# Math3D 2.0 defect and claim disposition

**Audit basis (2026-11-15):** `main` at `6c3d201244d2a0c1b70297063b078a2920d6ee57`, the [RC1 blocker register](RC1_ACCEPTANCE_GATE.md), [closure checklist](RELEASE_CLOSURE_TODO.md), [source-freeze readiness snapshot](SOURCE_FREEZE_READINESS.md), [four-journey installed gate](FOUR_JOURNEY_INSTALLED_GATE.md), [performance gate](PERFORMANCE_RESILIENCE_GATE.md), [installation gate](INSTALL_UPGRADE_GATE.md), and [platform matrix](PLATFORM_CAPABILITIES.md). The GitHub issue tracker had no open issues at this review. The memory work and later source changes are still active. Recheck every disposition at the final frozen commit; an unsigned Dev installer and earlier source checks do not qualify the signed candidate.

**Decision rule:** Blocking means the four required Windows journeys or their release integrity cannot be claimed until the stated check passes. Limited means a named capability may be offered only with the shown boundary and refusal behavior. Deferred means the feature is outside the four required journeys and must not appear as completed 2.0 scope. Resolved rows below are historical defects whose named source or copy gap has closed; their separate candidate gate remains listed. A source test never substitutes for a signed, installed, or hosted receipt. Data loss, false scientific verification, invalid provenance, unsafe runtime exposure, broken supported 1.x migration, and a supported clean-install failure always block release.

## Gate crosswalk and host decision

Every [closure checklist](RELEASE_CLOSURE_TODO.md) row has a disposition: #1 is this scope decision; #2–3 map to D01; #4–6a to G01–G04; #7–8 to D04/G05; #9–10 to G05/D01, with D06's smoke assertion resolved; #11–13 to D02/G05; #14 to D01/D03; #15–18 to limited host claims; #19 to D05/G07; and #20 to G05/G07. The [RC1 register](RC1_ACCEPTANCE_GATE.md#current-blocker-register) remains authoritative for a final freeze, including Project resource integrity, scientific truth, native-source ownership and signing. No row in this document certifies a gate as passed.

**Windows is the only proposed primary GA host.** Its four journeys, core first launch and supported 1.x migration must pass on one signed candidate. Local browser is a source-tested subset. Hosted browser, physical Android and installed Linux remain limited until their final-host receipts exist. Do not promote the public site, Gallery or download copy beyond those host claims. Reopen this register after memory work and later source merges, after any new defect report, and at the exact RC1/RC2 freeze.
