# Guided Study Gallery acceptance matrix

The Projects Gallery presents 16 curated entries, including the candidate Volume → Mesh starter. Its metadata lives in `renderer/src/projects/curatedStudyCatalog.ts`; this page records how each route is qualified. A Gallery card is guidance, not evidence that a computation ran on the current host. Project Results, Study panes and published Workbooks apply exact-source checks.

**2.0 advertising decision:** The 12 built-in Project cards are guided, source-backed research examples for the qualified desktop source path; their installed-candidate status remains open. The Volume → Mesh entry is a candidate source Study and its extraction path remains under qualification. QWZ, SSH and hydrogen are conditional verified-bundle import cards, not bundled completed Studies. Algebra structures is a saved-definition entry, not proof of a Sage run. The Catenary/Catenoid evidence path supplies the bounded Surface/Curve/Mesh comparison story. The complete QWZ and CAS flagship journeys require their external scene or live Sage route and exact-candidate tests before an unconditional product claim. Browser previews remain read-only where editing cannot preserve source evidence. See the [release scope](RELEASE_SCOPE.md) and [roadmap scope decision](ROADMAP.md#advertised-20-journey-scope).

All 12 built-in Project routes now create a guided copy with saved Study pane pins, a source-bound Note and a Workbook citing the Study. The four Mesh evidence/comparison routes gained their first saved Study. Ordinary Starter copies retain their previous contents. The renderer matrix test exercises every guided route through package save/reopen, source revision change, narrative export, verified independent import preview and a removed Workbook payload. It checks that changed citations become historical, changed Note anchors lose current status, and missing Workbook bytes prevent import. Where a journey has other pre-existing Notes with legacy anchors, the narrative export lists those as omissions instead of presenting their text as current. The Volume → Mesh entry begins with a source-only Study; a later current extraction creates a separate two-pane Study and result citation.

The active Gallery now qualifies each card against probed storage, WebGL and verified-scene chooser facilities. It reports measured Project and raw sidecar bytes after a copy is prepared, and says “unmeasured” beforehand. Desktop guided open focuses the saved Study; New copy keeps the old Project and its evidence. Browser cards that need desktop editing provide a read-only research preview with Study source, Workbook citation and Note status. Mobile's saved Project explorer shows citation pins from verified Workbook bytes and marks legacy citations unverified.

## Source and platform rules

- Built-in Projects create independent identities. A guided copy receives a `curated-study-v1` tag; the ordinary Starter projects path and existing saved copies are left as they were. “New copy” creates another Project instead of overwriting an edited one.
- Research narrative JSON is checksum-verified, then its citations, Note status and omissions are recomputed from the enclosed Project package before the import preview. The UI lists all three and the host's document/resource compatibility. Import refuses an ID already in the library or active workspace; it never overwrites that Project. To keep two copies on one host, create and export a new guided Project copy with a fresh identity.
- Study panes, Workbook citations and new source-bound Note selections save their exact source generation and resource descriptors. Older references retain their saved source revision and are marked legacy-unpinned; migration never borrows descriptors from a later live source.
- The three quantum cards contain no `.qscene` bytes. Scene import is enabled only when the desktop preload exposes the verified chooser. A local bundle can be reopened offline; producing one is separate work. The chooser verifies bundle integrity, while the card asks the user to select the corresponding model.
- The CAS card opens existing structural examples. Saving one needs a named Project. Its expected answers and failure cases describe validated definitions, not an independently verified Sage run.
- Generated Mesh and producer-scene byte counts depend on resolution. The linked baseline measures specific built-in copies; numeric download, first-open time and memory budgets for the release candidate remain open.
- The SVG starter artwork is illustrative. The linked UI captures identify their source build and host, but are not installed release-candidate media.

## Reproduce this slice

1. Run `npx vitest run renderer/src/projects/galleryDesktopCompatibility.test.ts renderer/src/projects/flagshipNarrativeMatrix.test.ts renderer/src/projects/curatedStudyQualification.test.ts renderer/src/projects/curatedStudyPreview.test.ts renderer/src/projects/projectResearchNarrativeImport.test.ts tests/unit/mobileProjectExplorer.test.ts`.
2. Run `npm run build:core` and `npx tsc -p renderer/tsconfig.app.json --noEmit`.
3. Run `npx playwright test tests/e2e/project-curated-gallery.spec.ts --reporter=list` in a source checkout with Electron available. The Catenoid copy must reopen its Surface/Mesh Study and navigate to the comparison result. Build web, then run `npx playwright test -c playwright.graph2d.config.ts tests/graph2d-web/curatedGalleryFallback.spec.ts --reporter=list` for local Chromium.
4. In Projects → Starter projects, switch to Guided Studies. Filter Quantum scene and confirm three external-source cards. Filter Algebra and open the CAS examples. Open the Catenary guided copy and confirm its saved two-pane Study after restarting the desktop app.

The M3D20-07 built-in research narrative exit has an automated renderer-host matrix. M3D20-08 source-checkout routes now have working open or honest preview paths. Its full release exit remains open for installed-host coverage of every route, hosted browser and Android device receipts, independently verified external scenes, and release-candidate performance budgets.
