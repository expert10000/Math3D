# M3D20-18b — GA sign-off identity

The current 2.0 source tree has no approved release sign-off. After the v2 RC2 rehearsal passes, keep a reviewed `math3d/release20-ga-signoff/v1` JSON receipt **outside** the source checkout. It must contain `status: "approved"`, `tag: "v2.0.0"`, the exact `sourceCommit` and `installerSha256`, SHA-256 values for the candidate manifest, RC2 rehearsal report, and final release notes, a reviewer and review timestamp, an empty `blockers` array, an explicit `knownLimitations` array, and `publishedPlatforms` listing Windows plus Linux only if qualified. Both the sign-off limitations and release notes must state that reference-host mixed-route memory plateau and installed memory qualification remain open for 2.5 or later; a hosted source pass is not either of those receipts.

Run `node scripts/verify-release20-ga-signoff.mjs <signoff> <candidate> <rc2-report> <release-notes>` against the reviewed commit. The verifier refuses mixed source/artifact identities, changed notes or receipts, outstanding blockers, false or missing memory disclosures, and notes missing changes, compatibility, limitations, migration, or release evidence sections. It does not perform review itself or infer approval from passing tests. Reissue the sign-off after any changed candidate, report, notes, or source commit.
