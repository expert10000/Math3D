The worker reported backend `bundled-exe`, version `1.0.0`, and artifact SHA-256 `1ade3d6c91352541e0ec56d8776eb50e6de0e9ff33078597c00c3ca73cc3e9e7` in all three formats. For AppImage, upgrade and rollback mean switching the executable against one isolated profile; AppImage has no package-manager installation. The deb and rpm checks used `apt-get install` and `dnf install`/`dnf downgrade`. The [phase receipts and profile inventories](evidence/m3d20-18-linux-upgrade-43603054286) distinguish exact Project checkpoint preservation from full-profile restoration. The upgrade's modified profile is not asserted byte-identical to 1.7; the original backup is preserved and restored before rollback.
