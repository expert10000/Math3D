# GF-07 — saved derived profile Graph handoff

**Status:** first bidirectional desktop gate implemented, 2026-11-04.

Graphs can open the GF-03 magnitude → plane slice → line profile as a saved point-series row. The row uses GF-04 computed samples and stores a separate `project-derived-profile/v1` origin: Project ID, verified source generation, the three exact derived-document identities, the saved physical line selection ID and structural hash, profile cache key, sample-row hash, method, axis and unit. Its origin is mutually exclusive with older Graph point-series origins. Existing rows retain their previous schema.

The Graph sampler receives the row only while the active Project, source, recipe and selection still match that origin and the saved point table has the recorded row hash. Missing or changed sources, unverified sources, changed recipes or selections, and missing sample bytes withhold values. The Graph inspector shows the saved references and withholding reason. **Locate selection in Field Explorer** opens the source and focuses the saved selection; it does not construct a replacement selection or provenance.

**Refresh profile row** explicitly runs the GF-04 brokered job against the currently verified GF-03 chain, then edits the row and its origin in one Graph command transaction. It is available after the current Project recipe and a matching physical selection have been verified, including when the previous Graph origin is stale. A source edit first needs a current verified derived recipe; GF-07 does not silently rebase the GF-03 operations. Undo restores the prior Graph row in one step. The job's source-generation guard and a Project identity check prevent a late computation from publishing a stale row.

The focused contract test saves the Graph row inside a Project, serializes and reopens the Project and Graph document, checks exact references and table rows, changes or unverifies the source, and exercises one-step undo/redo. The desktop gate imports the GF-03 vector source and chain with its original selection IDs, opens the profile in Graphs, and returns to the physical line in Explorer. The original full fixture's legacy Graph tables lack sidecar bytes, so the desktop import gate uses its vector-only Project projection.
