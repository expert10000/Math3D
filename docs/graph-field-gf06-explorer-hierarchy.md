# GF-06 — Field Explorer Project hierarchy

**Status:** first desktop reorganization implemented, 2026-11-04.

Field Explorer now indexes the active Project under **Sources, Derived, Selections, Results**. These are read-only views of the Project's existing entries, `DerivedFieldDocument` chain, `ScientificSelection` IDs, saved results, and the guarded GF-04 profile slot. A selection reveals its stored physical geometry and any source-generation pin; a missing pin is identified as missing rather than inferred. The profile's inspect action opens and focuses the shared GF-05 provenance card. The existing dataset library and vector source editor stay in the source controls pane.

The inspector offers **Layer, Probe, Analyze, Provenance** buttons and an **Overview** state. Overview opens with the existing controls visible, preserving direct access to established workflows. Each section button isolates the related controls; native buttons, links, details and lists preserve keyboard operation and useful screen-reader names. The selected section is announced through its heading. In narrow windows the visual order follows the DOM order: source controls, inspector, viewer. The Project hierarchy links directly to source controls; the profile inspect action moves focus to provenance.

The [GF-03 Project fixture](../tests/fixtures/derived-field/gf03-magnitude-slice-profile.math3d) includes legacy Graph point-table references without sidecar bytes, so the desktop importer correctly treats the full JSON as preview-only. The GF-06 desktop gate creates an importable vector-only Project from that fixture, preserving its vector source, GF-03 chain and vector-owned selection IDs. It checks the hierarchy, keyboard navigation, source-control reachability, profile focus and pane order at 760 px.
