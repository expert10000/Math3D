# QI-05/06 QWZ Project links and portable pack

The existing `math3d.quantum-scene-document` schema-version-1 reader now accepts optional `linkedViews` and `view` records. Each link names a companion scene fingerprint and typed same-result role. A Project admits these records only when both documents have the same run ID, result SHA-256 and model, each link is reciprocal, and the companion role agrees with the verified source objects. Existing documents without these optional records still parse. Each document keeps its own source fingerprint, external location, selected object and sample index. Admitting a second matching quantum scene through the Project panel links both documents. A test reopens the linked pair beside a native Geometry document and rejects a forged companion.

The `.qpack` folder is a bounded `math3d.quantum-project-pack/v1`. It stores a Project resource package with relative `scenes/<fingerprint>.qscene` links and deduplicated scene files under `blobs/<SHA-256>`. The Electron main process independently verifies every source bundle before export. On open it checks the pack inventory and all blob hashes, reconstructs exact `.qscene` directories in the local user-data cache, independently imports them, and returns their resolved locations. The renderer then relinks the Project through the existing exact-fingerprint API and presents its usual compatibility review before opening. Moving the pack to another drive or host needs no manual path edit. Altered blobs and changed source bundles are refused.

The pack owns its copied blobs. The local user-data cache owns reconstructed scene folders referenced by opened Projects, so this slice does not evict them automatically. The current limits are 16 scenes, 112 MiB for the Project resource package, 16 MiB per blob and 128 MiB total. Native Project resources are included through the existing verified resource-package format; separately linked scientific-scene folders are currently refused at export. This does not introduce a general artifact broker or alter the original external `.qscene` links.

Checks: `renderer/src/projects/projectQuantumScenes.test.ts`, `renderer/src/projects/quantumPortableProject.test.ts`, and `tests/e2e/quantum-qi06-portable-project.spec.ts` cover link persistence, relocation, reimport and tamper refusal.
