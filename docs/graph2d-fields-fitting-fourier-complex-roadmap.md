# Graphs fields, fitting, Fourier and Complex Analysis follow-on

This records the requested scope beyond the delivered Graph → Geometry promotion. The items below are separate milestones so the UI and document contracts can be reviewed without treating a field preview as a saved Graph object. The 3D point-cloud overview covers the domain but is a bounded sample, with exact planes available for inspection.

| ID | Scope | Status and acceptance |
| --- | --- | --- |
| GRA-13.1 | Import verified components of 2D complex and vector grids as distinct Graph lines | Software delivered. Keep one source session open, choose a component, axis and fixed coordinate, reverify on every preview, preserve the component and line provenance, and allow several distinct lines. Unit and Electron checks cover both component types. |
| GRA-13.2 | View verified 2D fields and 3D volumes/planes | Software delivered for desktop. A whole 2D component is shown as a bounded heatmap. A 2D vector dataset can show both freshly verified components together as at most 512 arrows/stationary points, with explicit axis and magnitude units. A 3D component has a rotatable volume point-cloud overview covering the full domain (at most 32 samples per axis) and exact selectable planes. Every preview re-reads the source and checks transfer checksums; changed or missing resources clear the preview. This is read-only and does not persist a Graph field object. Transfer functions and mobile viewing remain open. |
| GRA-13.2a | Pinned scientific field presets | Software delivered for desktop. Graphs → More → Author → Scientific field presets opens five deterministic, hash-pinned bundles: sine–cosine and thermal scalar grids, a 2D complex wave packet, a 2D planar vortex and a 3D swirling flow. The complex and vector examples let users compare component lines and field views without selecting a folder. Presets are included in desktop packaging and have deterministic fixture, bundle-reader and Electron coverage. |
| GRA-13.3 | Save and reopen multidimensional field references | **Saved-reference and verified relink flow delivered on desktop:** individual field references store source location/fingerprint, component, axes, shape and resource hash without field values. A paired 2D vector reference stores both ordered components as one Project record; saving re-verifies the bundle, and reopening verifies both resources, metadata and transfer checksums before drawing arrows. Missing or changed sources withhold the display. Replacement pickers verify candidate bundles and show metadata differences. The paired review requires both ordered component names, axes, shape and both resource checksums to match; acceptance re-reads the bundle, verifies both component planes, and records one undoable Project change. Individual component relinking retains its own review. Graph persistence/undo, mobile read-only metadata and desktop missing/changed/matching journeys are covered. A standalone field document, mobile field-value visualization and physical-device signoff remain separate work. |
| GRA-14 | General vector fields | **Planar authoring plus the separate [3D vector-field document, live bundle verification, editor, bounded arrows and adaptive trajectories](graph3d-vector-field-contract.md) delivered on desktop.** The 3D document is a native Project workspace member, retaining seeds and solver policy through Project save/import/reopen. Derived arrows and trajectories are never persisted; scientific results require a fresh three-component source check. Long integrations run in a cancellable worker. The [packaged desktop gate](evidence/graph3d-desktop-acceptance-2026-10-24.md) passed on the Intel UHD 770 hardware renderer at 512 glyphs, with resize, camera, keyboard and readable status checks. Numerical regression now covers non-grid-aligned poles, asymmetric boundaries, unequal axis spacings and nonuniform decimated transfer positions. The Android Project explorer now has a read-only native arrow viewer that re-verifies complete external bundles on each request and displays at most 512 arrows. Android physical-device performance, source picker and spoken-accessibility signoff remain open; mobile trajectories are deferred until that gate passes. Human Narrator spoken-output signoff also remains open on desktop. |
| GRA-15 | Nonlinear fitting | **Two named models delivered:** exponential decay and positive-capacity [logistic growth](graph2d-gra15-nonlinear-uncertainty.md), each on the checksum-checked point table with editable initial parameters, bounded local Levenberg–Marquardt iterations, cancellation, failure/convergence diagnostics, residuals and fitted curves within the observed x extent. Exact, noisy, degenerate, checksum, cancellation, desktop and mobile parity tests cover both models. The uncertainty assessment deliberately withholds parameter intervals and confidence/prediction bands because their inferential assumptions and local-conditioning gates are not established. Physical-device/accessibility signoff remains open. |
| GRA-16 | Fourier analysis | **[Checked scalar and aligned multi-channel slices](graph2d-gra16-multichannel-fourier.md) delivered on desktop:** a bounded radix-2 FFT (zero padded to the next power of two) requires complete, uniformly spaced, checksum-verified rows. The multi-channel panel compares one to four point series only when their in-domain x coordinates match exactly; imported channels must declare matching x/y units, while manual channels carry an explicit unit-assumption warning. Each channel keeps its own spectrum, table checksum and source provenance; CSV exports all channels together. The mobile tool still uses the single-channel core result. Rectangular/Hann windows, peak/RMS amplitude, optional mean removal and explicit x/frequency units are available. Known tones, Nyquist, leakage, missing/irregular/changed rows and the desktop channel workflow have tests. Automatic resampling, mobile multi-channel UI, measured mobile performance and physical-device/accessibility signoff remain open. |
| GRA-17 | Graphs → Complex Analysis mapping | **[Parametric and paired-source contour workflows delivered](graph2d-gra17-complex-mapping.md):** desktop previews/downloads/places a bounded contour from `x(t)+i y(t)`, two explicit `y(x)` functions, or the checked real/imaginary point series of one verified 2D complex-grid slice. Scientific provenance includes source locator, axes, scene/dataset, manifest fingerprint and both component checksums. Desktop preview, acceptance and linked refresh reopen the original bundle and verify both component lines against imported point tables; missing or changed bundles are rejected. Complex reports Graph checkpoint status separately from a current-session external-bundle check. Changed Graph sources require reviewed refresh. Mobile project explorer shows a read-only contour/provenance summary and labels the external bundle unchecked. Refresh starts a new adapter checkpoint; export a Project snapshot first to keep the earlier version. Mobile Complex editing and physical-device/accessibility signoff remain open. |

The 3D field document, verified renderer, Project persistence and cancellable trajectories are delivered on desktop. Packaged-app performance passed on the measured Windows PC; human Narrator spoken-output review remains the desktop acceptance gate. The read-only Android 3D arrow viewer is implemented, pending physical-device measurement and accessibility review before mobile trajectories. Mobile Complex editing remains separate product work.
