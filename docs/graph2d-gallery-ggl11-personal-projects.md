# GGL11 — My Graphs and reusable copies

Desktop/web and native Gallery now expose My Graphs: search existing Graph projects, open a preserved project, save an independent reusable copy, and filter project favorites. Favorite preferences are bounded, versioned references; project payloads remain in the existing desktop checkpoint/native library stores. Corrupt preferences report an error and require an explicit reset without hiding saved projects.

Copying forks Graph and retained Curve/Surface document identities, remaps companion links and relations, preserves original table references after verifying sidecars, and starts an independent handoff ancestry. Original mathematical object IDs, expressions, ranges and point rows are retained. Copied result observations receive fresh result IDs plus the original result/source generation in their provenance and an explicit not-recomputed warning. Stale source generations remain stale. Unsupported non-checkpointed/other-module collections are rejected with an explanation.

Opening or copying preserves current edits before switching. Desktop uses the existing rollback transaction; native saves one planned library replacement before replacing its live graph. Storage/quota, missing-sidecar and corrupt-checkpoint failures retain current work. Returning to an original and edited copy restores their independent source values.

Verification covers mixed Graph/Curve/Surface copy/round-trip/provenance, existing checkpoint enumeration, quota rollback, missing sidecars, bounded preferences and current-edit preservation, plus the real browser/Electron My Graphs flow. Combined software acceptance is recorded in the final delivery evidence. Physical native accessibility and signed device release checks remain pending.
