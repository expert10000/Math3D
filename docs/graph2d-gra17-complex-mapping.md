# GRA-17: sampled Graph contour to Complex Analysis

The first mapping accepts one saved Graphs parametric object `x(t), y(t)` with finite values and included endpoints. It samples 16–4097 points over the stated parameter domain and maps each point to `z(t) = x(t) + i y(t)`. The destination is a versioned Complex Analysis document containing a polyline contour and the identity function `f(z) = z`. It does not infer a complex analytic function from the real Graph expressions.

The desktop Graph inspector reviews the point count, closure, endpoint gap and tolerance, largest sampled step, coordinate domain, source revision/hash and limitations. Auto closure requires the sampled endpoints to agree within `10⁻⁶ × max(real range, imaginary range, 1)`; explicit closed mode rejects a larger gap. Undefined or stationary paths are rejected. The preview is re-sampled against the same Graph document revision/hash before download or direct placement in Complex Analysis. The target carries the Graph document/object identity, source revision/hash, sample count, closure policy, mapping name and target structural hash. The source-status API distinguishes current, changed, missing and locally edited targets. The Complex workspace shows that status; when the Graph has changed, it previews old and new revisions, hashes, point counts and domains, then rechecks both documents before applying refresh. Refresh preserves the target identity only when the target is unedited and the matching Graph source is available.

Sampling is bounded and does not establish path smoothness, winding, enclosure, analyticity or convergence of contour integrals. A narrow unsampled excursion or singularity may be missed, and the target sets winding to unknown. The mapping is geometry only. Refresh replaces the active Complex adapter checkpoint after explicit review; its earlier edit undo stack does not carry across that replacement. Export a Project snapshot before refresh if the earlier target must remain recoverable. Verified complex field/paired independent Graph source mapping, mobile target workflow and physical-device/accessibility signoff remain open.

Acceptance includes a circle round trip through Complex Analysis serialization, changed/missing-source and edited-target diagnostics, undefined/closure/degenerate rejection, retained open closure across refresh, and desktop preview/download/place/change/review/refresh/Project-save/reopen/add-another journeys.
