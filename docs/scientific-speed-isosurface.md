# SCI-09 bounded speed isosurface

Field Explorer extracts one physical `|F|` level inside its saved physical clipping box. The worker samples at clip planes and regular source-grid points, reducing the lattice to at most 64,000 cells. It marches six tetrahedra per cell and stops at the saved triangle budget (1–100,000; default 40,000). Intersections are keyed by source-grid edge (or exact grid node), so adjacent tetrahedra and cells share indexed vertices. Area-weighted vertex normals point toward increasing speed.

The UI reports vertex and triangle counts, physical mesh bounds, connected components, boundary edges, clip-plane boundary edges, nonmanifold edges, and whether the completed mesh is watertight. A positive clip-plane boundary count labels a surface opened by the physical clipping box; budget exhaustion is labelled incomplete. These are measurements of the extracted approximation, not a claim about the topology of the continuous field.

For v3 scenes, the worker requests only tiles used by this lattice, read through the existing manifest-pinned verifier and admitted into the 64 MiB verified tile cache. It checks the tile checksums again on worker admission. V1/v2 scenes use the existing verified bounded-volume path; authored expressions are evaluated in the worker. Cancellation terminates the worker and publishes no partial mesh. A failed source check clears the preceding mesh.

The exported self-contained glTF carries physical positions, vertex normals, and a triangle index buffer. Its `extras` record contains the source document identity, source references and source hash, coordinate axes and units, selected level, clip, lattice shape, budget, completion and clipping flags, topology counts, and the verified tile indices and hashes. Project documents save the level, triangle budget, and clip as a regeneration recipe; they do not store mesh bytes. Reopening requires a fresh extraction and fresh source verification before the mesh appears.

The analytic `F=(x,y,z)` fixture checks the unit-radius `|F|=1` sphere: sampled vertex radius within 0.035 m, outward normal dot radial direction above 0.8, each bound within 0.04 m of ±1 m, one connected component, and zero boundary or nonmanifold edges. A clipped sphere checks open clip-plane edges; a synthetic three-triangle edge checks the nonmanifold counter. The tests also cover budget exhaustion, indexed glTF metadata, recipe round-trip, and Electron's glTF download handoff. The measured Burgers desktop test checks a narrowed clip touching 48 of 72 tiles per component (3,478,200 resident bytes), open clip-plane boundaries, accepts a changed tile outside that clip, rejects a changed tile inside it, and checks cancellation, mesh export contents, and regeneration after Project reopen.
