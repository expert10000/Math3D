# UTe2 Study consumer roadmap

**Started 26 November 2026.** This is a feature track for a new Theory Lab scientific journey, not a Math3D 2.0 GA journey. The [Theory Lab source and producer plan](https://github.com/expert10000/theory-lab/blob/main/docs/UTE2_JOURNEY_ROADMAP.md) owns the physics and immutable runs. The user-supplied nine-page UTe2 chapter is pinned there by SHA-256, but its PDF is not republished in either repository.

## Consumer boundary

Math3D will visualize and cite verified Theory Lab results. It will not fit the material, choose a UTe2 pairing symmetry, minimize the Landau functional, diagonalize a BdG matrix, or calculate a Chern number on import. The October 2026 ultrasound work supports thermodynamic multicomponent competition and a fluctuation regime; the chapter's 2×2 BdG, p_x/p_y, and square-lattice chiral examples are pedagogical. A toy Chern number or edge state must never be presented as a measured UTe2 topological phase or Majorana observation.

## Product journey

1. **Source:** Open a Lab-produced, hash-verified run and scene bundle. Identify its model class (`two-component GL`, `single-sector BdG`, or `class-D lattice toy`), parameter conventions, solver method, source chapter section, and whether a value is observed, inferred, or calculated in a toy model.
2. **Study:** Create a Project-owned Quantum Study from exact GL minima/phase-map or k-space energy/gap/phase scenes. Persist immutable source fingerprints and separate mutable camera, selection, and layout state. Reopen the exact source before showing selected values.
3. **Inspect:** A GL selection can show supplied free-energy/minimum and stability values. The reduced BdG selection uses dimensionless ξ, which is not momentum; the separate lattice toy selection uses sampled kx and ky. Both show saved energies and weights only where defined. Pairing phase is undefined at zero pairing magnitude, and weights are undefined at a zero-energy degeneracy. A topology selection can show a supplied invariant only with a full-gap and convergence receipt. Never infer missing samples, phase, experimental boundary positions, or topology from colors.
4. **Cite and transfer:** Export a bounded JSON evidence report and a Workbook citation with run/result/scene/dataset hashes, units, numerical method and omissions. Reopen after restart and Project transfer. Changed or absent source withholds values and labels the reason.

The first consumer uses Theory Lab's UTe2-4 scene producer without a schema change. Its `quantum-scene/v1` fixture contains four stationary candidates and stable/global role subsets from one bounded, dimensionless Landau result. Math3D reopens the exact bundle before showing a selected candidate and checks its free energy against declared coefficients; it does not minimize or extrapolate a phase diagram. `npm run test:quantum:ute2-landau` covers import, altered and forged source refusal, Project save/restart, selection, and value withholding after source mutation. The chapter PDF remains local and is absent from the fixtures. This track is independent of QI-40 installed-pair certification, trusted Windows GA signing, and deferred memory qualification.

The BdG consumer uses four more exact Lab worker exports: gapped and node cases for the reduced constant-gap sector, and gapped and sampled-node cases for the square-lattice toy. The reduced selection checks symmetric branches, defined positive-branch weights and the omitted zero-energy weight; it reports ξ as a dimensionless dispersion parameter. The lattice selection independently checks the ordered half-open k-grid, energy and pairing arrays, scalar units, and binary masks before showing one linked Study point. Undefined phase and weights are explicit nulls. `npm run test:quantum:ute2-bdg` covers source integrity, a forged mask with recalculated hashes, Project/Workbook serialization and portable transfer, desktop save/restart, and value withholding after source mutation. These finite samples establish neither a continuous bulk gap nor a UTe₂ material phase. Installed-pair qualification remains M3D-UTe2-4.

The conditional topology consumer uses four exact Lab bulk receipts. Each is one parameter-space point, since the saved bulk result supplies no drawable momentum grid. Math3D checks the producer's exact continuous-gap scalar, sampled fine-grid minimum, two-mesh link and independent curvature diagnostics before showing the supplied toy Chern value. Gap closure and unresolved convergence keep the value null. An independently admitted finite-strip scene may add two width profiles only when its saved bulk parent run, result hash and invariant match the qualified receipt; the finite-width observation does not assert a zero mode, infinite edge or Majorana particle. `npm run test:quantum:ute2-topology` covers the nontrivial, trivial, closed and unresolved receipts, separate strip linking, changed and forged source refusal, Project/Workbook serialization, and desktop save/restart with changed-source withholding. These are spinless class-D toy results, with no UTe₂ material claim.
