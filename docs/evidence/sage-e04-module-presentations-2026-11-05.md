# SAGE-E04 module presentations — 2026-11-05

CAS → Algebra → Structures → **New module** now saves three versioned object forms: a free module `R^n`, a presented module `R^n / im(A)`, and a matrix map between saved free modules. The presented module stores named ambient generators and a typed relation map `A:R^m→R^n` with exactly `n` rows and `m` columns. A separate map object pins source and target module revisions and stores a target-rank by source-rank matrix. The dossier shows these dimensions, entries, ring and parent revisions. No quotient rank, invariant factors, kernel or image classification is inferred at E04.

The base ring is a saved `ZZ`, `QQ`, or polynomial ring directly over saved `QQ` with at most three variables. Ambient and relation ranks are bounded to six; scalar expressions are short and exact. `ZZ` entries are canonical integers, `QQ` entries are reduced rationals, and polynomial entries use only variables of the pinned ambient ring. The Project registry rejects missing parents, invalid matrix shapes, duplicate generator names, wrong-ring entries, maps with mismatched ranks or rings, and maps whose source or target has relations. This free-map restriction avoids claiming that a matrix descends to a quotient without a membership certificate. Existing revision freshness logic marks modules and dependent maps stale when a pinned ring or module definition advances.
