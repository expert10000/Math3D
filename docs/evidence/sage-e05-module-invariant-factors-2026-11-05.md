# SAGE-E05 ZZ module invariant factors — 2026-11-05

CAS → Algebra → Structures → select a saved `ZZ` module → Operations → **ZZ module invariant factors** now runs a typed, revision-pinned Smith calculation. The request carries the module and parent-ring IDs, revisions and definition hashes, plus the exact relation map `A:ZZ^m→ZZ^n`. A `QQ` or polynomial-ring module has an explicit incompatible-domain reason. The worker advertises this operation only on its Docker Sage route; when that route is unavailable, the control remains unavailable with the runtime reason. No freeform Sage source is accepted.

The result classifies `coker(A)` as a direct sum of `ZZ` free factors and nontrivial `ZZ/dZZ` torsion factors. A zero-column relation map gives a free module; a unit Smith diagonal contributes no torsion factor, so a fully related rank-one example is the zero module. For nonempty maps the worker supplies unimodular Smith transformations `U,V`; the core recomputes `U·A·V=D`, checks both determinants are ±1, diagonal divisibility, rank, free rank and torsion orders. It rejects a missing witness, a false torsion order or a result tied to an altered matrix. The Inspector shows decomposition, Smith form, free rank, torsion orders, exact verification and runtime provenance. A compact explorer renders one card per direct summand.

**Acceptance:** Core tests cover `ZZ²/im(diag(2,6)) ≅ ZZ/2ZZ ⊕ ZZ/6ZZ`, `ZZ²/im([2,0]ᵀ) ≅ ZZ ⊕ ZZ/2ZZ`, a free rank-two module, and the zero module; forged factors, forged transformations, changed snapshots and an unavailable route are rejected. The live worker suite passes on WSL Sage 9.5 and Docker Sage 10.10, including a nontrivial `[[2,4],[4,10]]` transformation. Main and renderer builds pass. The desktop test runs the capability-gated operation through a controlled Sage response, displays the decomposition, exports the actual Project package and independently imports it in a fresh profile with the same saved result and target hash.

The live worker suite verifies the backend computation on both installed Sage versions. The desktop test isolates persistence and UI from service availability with a controlled response; it does not claim that desktop HTTP dispatch against Docker was exercised in that test.
