# SAGE-E02 GAP operations for saved finite groups — 2026-11-05

CAS → Algebra → Structures → select a saved finite group → **Operations** now offers **GAP group invariants** when the Docker Sage route advertises `sage.group.dossier`. The operation accepts no code or freeform group expression. It sends the selected E01 definition, Project ID, object ID, revision and definition hash. The Inspector retains the exact group order, center, conjugacy classes, complete subgroup list with normality, action degree, GAP version, Sage version and saved runtime provenance. Project export and independent import retain the result against the same immutable group revision.

The worker constructs the group from validated named image permutations or disjoint-cycle actions of finite abelian invariant factors. It calls GAP through Sage for the order, center, conjugacy classes and subgroups. The app independently rebuilds the bounded permutation action and checks the full element set, center, conjugacy partition, complete subgroup enumeration and normality before accepting a result. A forged center or missing subgroup is rejected, as is evidence whose definition snapshot differs from the pinned Project object.

The complete-dossier limit is **group order ≤16 and action degree ≤8**, with at most 128 subgroups. Larger E01 definitions remain valid saved objects and show a specific operation eligibility reason. A runtime without working GAP omits the operation from its advertised capabilities; the UI shows the unavailable route. A failed or incomplete enumeration is not saved as complete evidence. The result uses element indices into the lexically sorted exact permutation list; these are stable for a pinned definition.

**Acceptance:** Local WSL Sage 9.5/GAP 4.11.1 and Docker Sage 10.10/GAP 4.15.1 each returned `(order, center size, subgroup count, conjugacy class count)` of `C4=(4,4,3,4)`, `V4=(4,4,5,4)`, `S3=(6,1,6,3)`, `D4=(8,2,10,5)` and `Q8=(8,2,6,5)`. Both routes matched D4's exact center, conjugacy partition, full subgroup membership and normality list. The D4 Sage 9.5 output is retained as an exact golden fixture. A separate live Docker HTTP worker advertised `sage.group.dossier` and returned D4 order eight, center size two, ten subgroups and five classes. Core tests check the full D4 payload, Project evidence save/reopen, forged results, mismatched snapshots, unsupported capability and oversized definitions. The controlled desktop test ran D4 through the advertised route using the exact Sage 9.5 payload, inspected its saved result, exported the Project, and reopened it in a fresh profile with the same record and evidence.
