# SAGE-F02 bounded real-locus rendering — 2026-11-05

CAS → Algebra → Structures → select a saved `QQ` polynomial ring or ideal → **Real-locus scene contract and plot**. After validating exact equations, finite Cartesian bounds and a sample cap, **Render bounded real locus** displays a numerical plot. One equation gives real roots in one variable, a marching-squares curve in two variables, or a marching-tetrahedra implicit surface in three variables. An ideal with two equations in three variables is supported when one equation is a linear plane; its plane section is contoured as a curve. Other higher-codimension systems report an explicit unsupported case.

The versioned sample embeds the complete F01 scene and its pinned algebra records. It records the algorithm, evaluation count, sampled points/segments/triangles and a structural hash. Completeness is always `bounded-sample`, with a visible warning that components, tangencies or singularities may be missed. The requested tolerance remains a recorded sampling setting, not a certified geometric error bound. The UI can export sample JSON and sampled Geometry JSON or save a sampled Geometry checkpoint in the Project. The Project comparison viewer reads that checkpoint as curve overlays or a surface mesh. Independent import recomputes the bounded sample from its exact source, rejects altered geometry and checks its pinned Project revisions.

**Acceptance:** Core fixtures cover the circle `x²+y²−1=0`, the implicit sphere `x²+y²+z²−1=0`, and `I=(x²+y²+z²−1,x−y)` over saved `QQ[x,y,z]`. They check curve/surface counts, numeric residuals, the exact plane relation, bounded-sample status, JSON/Geometry roundtrips, Project serialization/reopen, Project comparison render data, tampering rejection and an unsupported two-quadratic system. The desktop gate previews and exports the sphere/plane curve, saves its Geometry checkpoint, exports the actual Project package and imports it in a fresh profile.
