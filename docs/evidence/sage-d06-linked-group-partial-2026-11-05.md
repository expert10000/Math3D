D06 now saves its regular permutation action as an E01 finite-group object with a stable Project ID and source link: exact polynomial, polynomial-ring revision, splitting-field polynomial and Galois evidence ID. Project import verifies the link against saved evidence. A changed ring revision marks the group stale; the existing E02 eligibility gate rejects operations against that stale source.

The Galois viewer shows the polynomial, splitting field, group order and linked subgroup/fixed-field diagrams. For `x^4−2`, the D4 order-eight result is complete with ten pairs. Core verifies the shown permutation group, subgroup closure, normality and fixed-field degree law without claiming that a partial list is complete.
