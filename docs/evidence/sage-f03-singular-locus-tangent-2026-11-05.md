# SAGE-F03 singular-locus and tangent views — 2026-11-05

CAS → Algebra → Structures → select a saved `QQ` polynomial ring or principal ideal → validate a real-locus scene → **Exact tangent and singular-locus inspection**. Enter one bounded rational coordinate per axis and select **Inspect tangent and singular locus**. The Inspector lists the exact unsolved system `f=0` and all `∂f/∂xᵢ=0`, exact point membership, the Jacobian row and rank, the tangent-space equation, multiplicity as the degree of the first nonzero translated jet, and its homogeneous tangent cone. Two-dimensional views draw the point and each real tangent line. A smooth three-dimensional hypersurface produces a local tangent-plane patch in Project comparison.

The versioned analysis embeds the complete F01 scene and its pinned algebra object revisions. Its exact rational coefficients, point, Jacobian equations, local result and structural hash are independently recomputed on import. The UI exports standalone analysis JSON and Geometry JSON, or saves a Geometry checkpoint to the Project. A fresh import checks the embedded source records against the Project registry. The view explicitly says its singular-locus equations have not been globally solved and that scheme-sensitive multiplicity differs from a claim about the visible real point set.

**Acceptance:** `y²−x²(x+1)=0` at `(0,0)` gives multiplicity two and an ordinary real node with two tangent directions. `y²−x³=0` gives multiplicity two and an ordinary cusp with one repeated tangent and a nonzero cubic jet. On `x²+y²+z²−1=0`, `(1,0,0)` is smooth with Jacobian `[2,0,0]` and tangent plane `Δx=0`; `(0,0,0)` is off-locus. Tests verify exact derivative coefficients, JSON/Geometry roundtrips, saved Project reopen, comparison render data, tamper rejection and out-of-bounds rejection. A two-equation ideal and a constant polynomial are refused instead of receiving an incorrect hypersurface classification. The desktop gate exports both JSON forms, saves the node and cusp scenes, exports the Project package and independently imports it in a fresh profile.
