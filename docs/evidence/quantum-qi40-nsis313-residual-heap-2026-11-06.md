# QI-40 residual installed heap paths · 2026-11-06

The [pinned NSIS 3.13 installed candidate](quantum-qi40-nsis313-installed-candidate-2026-11-06.md) installs and runs its UI, upgrade, and rollback checks, but still misses the provisional 2 MiB late renderer heap target. These runs used the same candidate installer bytes and changed only the diagnostic harness.

The [control run](https://github.com/expert10000/Math3D/actions/runs/42268456457) measured **3,816,876 bytes** from cycle 20 to 80. The [E2E-hook ablation](https://github.com/expert10000/Math3D/actions/runs/42269400056) deleted four global diagnostic hooks at each measured snapshot and measured **2,229,472 bytes**, still **132,320 bytes above** target. The runs were on separate clean runners; their difference is not a controlled estimate of the hooks' retained size. The earlier [pre-lazy workbook ablation](quantum-qi40-geometry-workbook-full-dump-2026-11-06.md) also ruled out the hooks as the sole cause of the then much larger string retention.

The [bounded control paths](quantum-qi40-nsis313-new-retainers-control-2026-11-06.json) and [ablation paths](quantum-qi40-nsis313-new-retainers-ablation-2026-11-06.json) sampled the five largest arrays or objects present in the final snapshot and absent from the pre-cycle baseline, with at least 4 KiB of shallow size. Two 24,608-byte arrays are V8 property backing stores reached through React fiber/DOM props in both runs. Three 19,800-byte arrays are mesh indices under `workspace.datasets.items`; in the ablation they remain reachable through mounted React event props. These are shortest paths to individual objects, not a sum of retained size or proof of a leak. The control has 90 new large arrays/objects totaling 1,539,360 shallow bytes; the ablation has 76 totaling 1,296,992. Both retain one WebGL context and five textures, equal to baseline.

The next source investigation should trace why the mounted UI retains workspace mesh payloads across preview cycles and whether that storage is bounded, then rerun the same installed 80-cycle gate. The provisional limit remains unchanged and QI-40 remains open.
