# Hosted Private gateway Workbook evidence — 2026-11-05

The hosted web session gate now runs a successful GCD, a modular-inverse mathematical failure, and a cancelled modular-inverse job against the live authenticated Private gateway. Each result is saved to Workbook and checked again after page reload. The checks inspect the exact request, backend, outcome and typed error code. Compute records for the failure and cancellation are verified before reload because broker history is session memory, while Workbook evidence persists. Both browser sessions remain isolated and the original quota/authentication checks still run.

Cancellation occurs before a worker response can report its Sage version. Workbook records that version as `unreported` and retains the `cancelled` code and diagnostic; it does not substitute the version seen in a prior health probe. Success and mathematical failure record Sage 10.10.

The gate uses test-only access keys and a local loopback gateway. It verifies live hosted session behavior, not an external HTTPS deployment.
