# SAGE-G07 representations and group actions acceptance

Open a saved finite group in **CAS → Structures → Operations → Group action and characters**. Choose a point in its natural permutation action. The Docker Sage route advertises this operation only when GAP and irreducible-character methods are available. The existing E01/E02 limits apply: group order at most 16, action degree at most 8 and at most three named permutation generators. Requests pin the Project group ID, revision, definition hash and selected point. Jobs use the shared cancellation route, and results are capped at 16 KiB.

The result contains the selected point's exact orbit, stabilizer as element indices, generator permutation matrices, the fixed-point permutation character on every sorted group element, and conjugacy classes. The Inspector adds a finite action graph whose arrows mean application of saved generators, plus a selection readout. The app independently reconstructs the action from the pinned definition and checks the orbit-stabilizer identity, all matrices, fixed-point counts and conjugacy classes before retaining Project evidence.

When GAP's irreducible characters are all integer-valued, the worker returns complete rows and multiplicities in the permutation representation. Project validation checks row orthogonality, degree squares, multiplicity inner products and dimension recovery. The Inspector labels GAP's irreducible-row computation as reported. When any row contains nonintegral cyclotomic values, the result explicitly marks the table unavailable in this bounded integer-valued view and retains the orbit, matrices and permutation character. No decimal approximation or invented character value is presented.

Exact fixtures: the natural action of `S3` on three points has orbit `[1,2,3]`, stabilizer order two, and permutation character `1 +` the two-dimensional standard character. The `C2` swap has orbit `[1,2]`, stabilizer order one and decomposition into the trivial and sign characters. The `C3` regular action has a complete three-point orbit and a nonintegral irreducible table, which is explicitly marked unavailable. Invalid points and forged orbit, matrix or orthogonality data are rejected.

Acceptance results (2026-11-06): four local Sage 9.5 worker tests passed, including the C2, S3, C3 and D4 G07 fixtures. Three focused core/broker test files passed 78 tests. `npm run typecheck:noemit` and `npm run build:core` passed. The new desktop Playwright gate passed the C2 run, exact Inspector and graph checks, Project export and fresh-profile reopen. The existing E02 D4 desktop dossier gate also passed.
