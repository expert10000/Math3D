2.0 in preparation

Four scientific journeys targeted for 2.0.

These bounded workflows define the 2.0 release target. The images below show existing source-build views, not completed journey captures or screenshots of a signed 2.0 installer. The current release and downloads remain on the release page.

01 / Surface

Trace a surface result to its source.

Start from a saved Surface, derive a sampled characteristic Curve and tessellated Mesh, then compare qualified analytic and discrete curvature in a Project Study and Workbook. Each result retains its exact source relation. A sampled ridge and local error are not a continuous-geometry proof.

  1. Save Surface source
  2. Derive Curve and Mesh
  3. Cite qualified evidence

Current source: the connected desktop route has source-test evidence. 2.0 gate: the exact signed installed journey remains open.

02 / QWZ Study

Trace a QWZ sample across four views.

Admit two independently verified external producer scenes, pin one reciprocal-space sample in a four-view Study, and carry a bounded producer sample or section into a source-linked Graph and evidence export. Connecting those samples does not compute new band energies or independently certify the physical model.

  1. Verify producer scenes
  2. Pin a reciprocal sample
  3. Save Graph evidence

Current source: bounded QWZ Study and Graph paths have source-test evidence. 2.0 gate: external bundles and the exact signed installed journey must be qualified together.

03 / Algebra

Carry a CAS result into a geometric view.

Start with a typed polynomial or ideal, probe a supported Sage operation, and keep its exact equations distinct from a bounded real Curve or Geometry sample. Save the source, method, singularity evidence, and sampling limits. An unavailable Sage route is reported rather than assumed.

  1. Save algebra source
  2. Probe Sage operation
  3. Inspect bounded locus

Current source: bounded live Sage routes have source-test evidence. 2.0 gate: operation availability and the exact signed installed journey remain open.

Algebra source↓Qualified result↓Geometric view↓Project evidence
04 / Field Explorer

Return from a Graph row to its exact Field source.

Save a finite line profile from one static analytic Field on its declared plane, carry it into a source-linked Graph, and return from a selected row to the exact Field and position. A Project Study and Workbook cite the verified source and result. This does not claim arbitrary cross-document cursor mapping, inverse Field reconstruction, or time-dependent trajectories.

  1. Save Field line profile
  2. Inspect Graph row
  3. Return to exact Field

Current source: the connected Field, Graph, Study, and Workbook route has source-test evidence. 2.0 gate: the exact signed installed journey remains open.
