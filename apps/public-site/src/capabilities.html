“Tested source journey” records software tests on a source build. It does not certify a downloaded installer. A saved preview may be readable while a document editor or required source bytes remain unavailable.

Runtime checks that affect an operation

Bundled worker

Windows installers package a Python worker executable for supported operations. A separate Python install is not an end-user prerequisite. Source builds and local browser proxies need a configured backend.

External Sage route

Math3D probes the specific operation and Local WSL, Docker, or private gateway route. A reachable service does not make every Sage action available.

Saved source resources

Project packages can carry verified source sidecars. External quantum and scientific scene folders remain separate and are re-verified on open.

Browser and mobile facilities

WebGL2, persistent storage, background workers, network, and host file access are separate facilities. Mobile previews do not imply desktop edit or compute parity.
