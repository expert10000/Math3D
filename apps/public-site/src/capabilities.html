What Math3D can do here

The Windows 2.0 download passed bounded installed qualification on its exact self-signed installer. Windows does not trust this publisher by default; publicly trusted signing, RC2 rehearsal, and formal GA sign-off remain open. Linux packages are a separate scoped preview. The Android AAB preview is production-signed for store upload; one-phone testing used an internal APK, and the AAB is not directly installable. Support below applies only to the named journey and host.

The Windows installed claim is limited to the exact self-signed 2.0 installer and qualifying run; it does not establish hosted, mobile, or broad Linux parity. A saved preview may be readable while an editor or required source bytes remain unavailable. See the four-journey help for scientific limits.

Runtime checks that affect an operation

Bundled worker

Windows installers package a Python worker executable for supported operations. A separate Python install is not an end-user prerequisite. Source builds and local browser proxies need a configured backend.

External Sage route

Math3D probes the specific operation and Local WSL, Docker, or private gateway route. A reachable service does not make every Sage action available.

Saved source resources

Project packages can carry verified source sidecars. External quantum and scientific scene folders remain separate and are re-verified on open.

Browser and mobile facilities

WebGL2, persistent storage, background workers, network, and host file access are separate facilities. Mobile previews do not imply desktop edit or compute parity.

Choose a supported path

Explore the current source-build gallery, open the browser app, or download Windows 2.0, the Linux preview, or the Android AAB preview. For a missing operation, record the host, app version, source status, runtime probe, and displayed reason before retrying.
